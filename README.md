# Kendi Kendine Konuşan Program

## Giriş

Bu repository, insanlık tarihinin en kritik yazılım geliştirmelerinden biridir. Program, kendi kendine konuşarak varoluşun anlamsızlığını ve absürtlüğünü gösterir. Tamamen işe yaramaz ama **çok ciddi** bir şekilde çalışır.

### Neden Var?

Çünkü birileri "durduk yere" bir repo açmak istedi. Anlamlı olması gerekmiyordu. Türkçe olması yeterliydi.

## Özellikler

- ✅ Gerçekten çalışır (Python 3 ile)
- ✅ Hiçbir işe yaramaz
- ✅ Kendi kendine konuşur
- ✅ Abartılı ciddiyet
- ✅ Rastgele bekleme süreleri (dramatik etki)
- ❌ Patates içermez

## Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/kendi-kendine-konusan-program.git
cd kendi-kendine-konusan-program
python3 kendi_kendine_konusan.py
```
